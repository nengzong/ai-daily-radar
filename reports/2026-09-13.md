摘要:d-Matrix 将其 Raptor XPU 通过 NVLink Fusion 连接方式集成进 NVIDIA MGX 机架架构,借助 NVIDIA 已验证的网络、供电、散热与供应链体系,把自研芯片从原型推向大规模数据中心部署,官方称这是"风险更低的定制硅片规模化路径"。
为什么值得关注:公司在园区/工厂侧布局边缘算力或私有化大模型推理时,"自研芯片/加速卡接入成熟机架生态"是控制供电与散热风险的一种可参考路径,尤其在评估数据中心/机房扩容方案时有借鉴意义。
链接:https://blogs.nvidia.com/blog/d-matrix-nvlink-fusion/

链接:https://www.utilitydive.com/news/data-centers-manufacturing-us-electricity-use-eia/830038/

**2. 新论文 SpatialBlock:用合成积木堆叠任务提升视觉语言模型的空间智能**
摘要:论文提出 SpatialBlock 方法,通过构造大量积木堆叠类合成谜题作为训练/评测数据,专门增强大型视觉语言模型(LVLM)在空间关系推理上的能力,弥补现有模型在三维空间理解上的短板。
为什么值得关注:楼宇/园区场景大量依赖摄像头与三维点云做空间理解(设备定位、通道占用、异常检测),这类"用合成空间任务专项强化空间推理"的思路,对公司训练/微调面向楼宇场景的视觉模型有直接参考。
链接:https://huggingface.co/papers/2609.07064

**3. Kimi K2.8 突击发布,性能逼近 K3 且百万级上下文全员开放**
摘要:月之暗面发布 Kimi K2.8,官方称其性能已逼近尚未全量开放的 K3,并将百万级 token 上下文窗口向全体用户开放,不再限制为付费或内测用户。
为什么值得关注:百万级上下文全量开放意味着长文档/长会话类企业应用(如整份工程规范、长期运维记录一次性喂给模型)的成本门槛在快速下降,对公司评估国产大模型做知识库问答、长文档审阅类 Agent 的选型有参考。
链接:https://www.qbitai.com/2026/09/487688.html

**4. GitHub Trending:MathModelAgent 用 AI Agent 自动完成数学建模全流程并生成论文**
摘要:开源项目 MathModelAgent 是一款面向数学建模场景设计的 AI Agent,能够自动拆解建模任务、调用工具求解并生成完整的建模论文,当日新增 star 数在 GitHub Trending 榜单中位居前列。
