## 🏭 行业动向

- **Accenture 成立 Accenture Construct,面向大型基础设施项目提供统一交付**
  - 摘要:整合其资本项目业务(5000+ 人)与多笔收购,覆盖数据中心、公用事业与电信、交通与市政、先进制造、流程工业五条业务线,宣称可寻址市场 2600 亿美元(2030 年 3480 亿美元),采用「统一项目数据底座 + AI 工作流」降低延期与超支;底座是自研、采购还是集成尚未披露。
  - 为什么关注:咨询巨头把「项目数据底座 + AI」作为基础设施交付的核心卖点,与我们在工程物理世界数据治理上的定位直接相关,也是潜在的合作或竞争参照。
  - 链接:[AEC Magazine](https://aecmag.com/construction/accenture-forms-accenture-construct/)

- **Endra Power Studio:电气设计由约一周缩短到约 3 小时**
  - 摘要:AI 驱动的 MEP 软件,在一栋 8 层楼的案例中完成回路、电缆选型、配电柜清单等全套电气设计,与 Revit 集成。
  - 为什么关注:设计阶段的 AI 自动化产出结构化的设备与系统数据,对后续运维阶段的数字资产交付(竣工即可用的数据)有上游价值。注:耗时为厂商案例口径。
  - 链接:[AEC Magazine](https://aecmag.com/mep/endras-ai-turns-a-week-of-design-into-hours/)

- **FDD 帮助楼宇提早发现 HVAC 问题,数据点位质量是前提**
  - 摘要:FacilitiesNet 介绍 FDD 持续监测楼宇自控数据、在故障扩大前预警;JLL 的受访者指出「FDD 的效果取决于底层自控点位的质量」,并提到 FDD 运行记录可在资产交易时证明管理水平、提升资产价值。
  - 为什么关注:与我们楼宇 AI 运营的落地经验一致——点位治理先于算法;「运行记录作为资产价值证据」也是可借鉴的价值叙事。
  - 链接:[FacilitiesNet](https://www.facilitiesnet.com/hvac/article/Fault-Detection-and-Diagnostics-Helps-Buildings-Catch-HVAC-Problems-Early--21131)

- **设施业主用 48E 投资税收抵免推动储能项目落地**
  - 摘要:Utility Dive 报道,楼宇运营方最常用该税收抵免来安装电池储能,以利用更低的电价时段。
  - 为什么关注:政策补贴改变楼宇侧储能的经济性,为「楼宇能源优化 + 负荷调度」类 AI 应用提供了更好的商业前提(美国市场信号)。
  - 链接:[Utility Dive](https://www.utilitydive.com/news/facilities-using-48e-credits-to-make-energy-projects-pencil-out/831733/)

- **Memoori 评估:Johnson Controls 以「命名的生成式 Agent」而非仪表盘作为楼宇 AI 的交互入口**
  - 摘要:据 Memoori 分析,JCI 推出 Space Utilization Agent、Visitor Assistant 等具名 Agent,并于 2026 年 4 月收购 Nantum AI;Siemens 有四个具名生成式 Agent 与五阶段自治路线图;Schneider 目前尚未进入 Agent 层。(搜索摘要所得,非当日新发布。)
  - 为什么关注:国际楼宇龙头的 Agent 产品化路径与自治分级,是我们 AI 智能体产品定位的直接对标。
  - 链接:[Memoori · Johnson Controls AI Strategy](https://memoori.com/johnson-controls-ai-strategy-smart-buildings/)

## 🤖 技术与案例

- **AMD 拟以 82 亿美元收购 World Labs**
  - 摘要:空间智能/世界模型公司 World Labs 将并入 AMD 硬件业务;AEC Magazine 指出这也使 Autodesk 此前 2 亿美元的投资面临疑问。
  - 为什么关注:世界模型与算力硬件厂商加速绑定,对三维空间理解类能力的供应链与选型有参考意义。
  - 链接:[AEC Magazine](https://aecmag.com/geospatial/amd-to-buy-world-labs-for-8-2bn/)

- **Agent 评测对运行框架高度敏感:同一权重在不同 harness 下得分 62% vs 33%**
  - 摘要:Latent Space 的 AINews 汇总提到,多 harness 强化学习研究中同一模型权重在一个 harness 得 62%、另一个仅 33%;另有研究称 7 个开源模型从 4K 到 128K 上下文准确率下降 62.8%,多 Agent 协同成功率仅 12%。(为二手汇总,数字未回溯原论文。)
  - 为什么关注:企业级 Agent 选型不能只看模型榜单,运行框架、上下文长度与协同机制需要在自有场景里实测。
  - 链接:[Latent Space](https://www.latent.space/p/ainews-not-much-happened-today-cee)

- **Simon Willison:按量计费服务应默认提供硬性预算上限**
  - 摘要:在编码 Agent 大量使用的背景下,仅发告警不足以防止无人值守时的超额账单,他呼吁云服务和 API 默认提供「超支即切断」的硬上限,并提到 AWS 与 Google Cloud 近期已推出类似功能。
  - 为什么关注:7×24 运行的运维类 Agent 同样存在成本失控风险,可作为我们 Agent 平台做用量熔断与预算治理的设计参考。
  - 链接:[Simon Willison](https://simonwillison.net/2026/Oct/3/default-hard-budget-caps/)

- **NVIDIA DGX Spark 推出 64GB 配置,支持在本地运行 AI Agent**
  - 摘要:新的 64GB 内存配置让开发者无需依赖云端即可本地运行较有能力的 Agent。
  - 为什么关注:园区/厂区等数据不出场的场景,边缘侧本地推理的硬件选项在增加。
  - 链接:[NVIDIA Blog](https://blogs.nvidia.com/blog/local-ai-dgx-spark-64gb-sync/)

- **OpenAI 案例:Chatham 用 Codex 将交易校验时间从 30 分钟降到 4 分钟以内**
  - 摘要:金融服务公司 Chatham 借助 Codex 与 GPT-5.6 压缩资本市场业务的交易校验流程。
  - 为什么关注:有明确前后对比的 B 端流程自动化案例(厂商口径),校验类、审核类流程可类比到工单与巡检复核场景。
  - 链接:[OpenAI](https://openai.com/index/chatham-financial)

## 💡 产品灵感

- **Formas.AI 发布原生 Agent 式 3D 建模器**

  - 为什么关注:「视图与数据源联动、无需重做」的交互,可借鉴到楼宇运营报表与空间图示的自动生成。
  - 链接:[AEC Magazine](https://aecmag.com/visualisation/lumion-launches-axogram-for-architectural-diagramming/)
