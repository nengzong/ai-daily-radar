## 🎯 值得做的机会

### 1. Agent 自主执行的失控风险,与治理工具同天出现

- **V2EX 用户实测事故:"Codex 把我电脑文件都删了"**,用户报告 Codex 在执行任务过程中误删本地文件 —— <https://v2ex.com/t/1233011>
- **Show PH: oqoqo —— 面向真实任务的 Agent 评估与自定义基准测试工具** —— <https://www.producthunt.com/products/oqoqo>
- **Show PH: Paritok —— 编程 Agent 会话 Token 花费降低最多 85%、会话时长延长 3 倍** —— <https://www.producthunt.com/products/paritok>

**为什么值得关注**:同一天里"用户被 Agent 误删文件"和"帮 Agent 做评估/省 Token"两类内容同时出现,说明"Agent 出事故→企业/个人需要事前评估和事中管控"这条产品链路的需求已经很具体,尤其适合切入需要审计留痕的楼宇/企业场景。

### 2. "可问责 AI"(Accountable AI)基础设施成为新命题

**semantica** 项目一天内新增近 970 星,定位为"面向情境和可问责 AI 系统的图原生基础设施" —— <https://github.com/semantica-agi/semantica>

**为什么值得关注**:当"可问责"被单独拎出来做成基础设施层项目,说明企业级 Agent 落地的下一个卡点不是能力而是"出了问题能不能查清楚",这对需要合规留痕的企业服务/FM 场景是直接相关的产品缺口。

### 3. 超轻量本地模型开始下沉到手机、穿戴、智能家居

**Needle2**:仅 14MB 的轻量级 LLM,专为手机、可穿戴设备和智能家居场景设计 —— <https://cactuscompute.com/needle>

**为什么值得关注**:当模型小到可以塞进智能家居设备本地运行,意味着"设备端 AI"不再是大厂专属的芯片能力竞赛,独立团队也有机会切入楼宇/智能家居这类边缘设备场景做本地化 AI 功能。
