## 🏭 行业动向

- **AMD 拟以 82 亿美元收购 World Labs**
  - 摘要:AMD 将收购李飞飞创立的空间智能公司 World Labs;Autodesk 此前对其的 2 亿美元投资及 3D 环境生成技术的后续获取路径引发关注。
  - 为什么值得关注:3D 场景生成是楼宇/园区数字孪生的上游能力,硬件厂商下场意味着该能力可能被捆绑进算力平台,影响我们的技术选型与合作格局。
  - 链接:[AEC Magazine](https://aecmag.com/geospatial/amd-to-buy-world-labs-for-8-2bn/)、[Latent Space](https://www.latent.space/p/ainews-amd-buys-world-labs-for-82b)

- **Autodesk 确认 Forma 将"逐步"取代 Revit,并预告 2027 年 Agent 优先的独立 Assistant**
  - 摘要:Autodesk 表示越来越多的 Revit 工作将直接在其行业云 Forma 中完成;新 Assistant 将跨产品、跨项目,按项目上下文编排工具,而非让用户逐个选择应用。
  - 为什么值得关注:BIM 入口向云端与 Agent 迁移,直接影响我们与设计侧数据对接的方式,也是"以 Agent 为入口"产品形态的行业样本。
  - 链接:[Autodesk 确认 Forma 将取代 Revit](https://aecmag.com/bim/autodesk-confirms-forma-will-replace-revit-over-time/)、[Autodesk 独立 Assistant](https://aecmag.com/ai/autodesk-extends-reach-of-ai-with-standalone-assistant/)

- **Accenture 成立 Accenture Construct,面向大型基建业主**
  - 摘要:埃森哲将资本项目业务整合为新实体,以 AI 与共享数据平台支撑,定位"单一责任伙伴"。
  - 为什么值得关注:咨询巨头把资本项目全周期交付产品化,是大型业主侧 AI 落地与数据平台需求的信号,也是潜在的竞合对象。
  - 链接:[AEC Magazine](https://aecmag.com/construction/accenture-forms-accenture-construct/)

- **纽约市多数建筑在首个合规年度达到排放标准**
  - 摘要:建筑通过热泵、围护改造和能源管理系统等手段达标;另有报道称商业储能市场未来五年预计增长 27%。
  - 为什么值得关注:强制性碳排法规已产生实际合规结果,能源管理系统是达标手段之一,验证了楼宇能效运营的政策驱动需求。
  - 链接:[Utility Dive](https://www.utilitydive.com/news/most-nyc-buildings-met-emissions-standard-in-first-compliance-year/831620/)

## 🤖 技术与案例

- **EngiWorld:前沿 Agent 在专业工程软件环境中能交付什么?**
  - 摘要:覆盖 CAD、CAE、CAM、BIM、EDA 等 6 个工程领域的 Agent 能力系统评测。
  - 为什么值得关注:直接对应"工程物理世界 AI"的能力边界,可作为我们评估 Agent 在工程软件中落地的参考基准。
  - 链接:[arXiv 2609.37686](https://arxiv.org/abs/2609.37686)

- **Anthropic 发布 Claude Opus 5.5 与 Sonnet 5.5**
  - 摘要:Sonnet 5.5 比 Sonnet 5 快 30%、多数任务成本最高降 30%;Opus 5.5 运行成本比 Opus 5 低 40%。社区反馈编程与图表理解提升明显。
  - 为什么值得关注:成本与速度同步下降,直接影响企业级 Agent 的模型选型与成本测算。
  - 链接:[Anthropic News](https://www.anthropic.com/news)、[Ben's Bites](https://www.bensbites.com/p/sonnet-55-is-worth-a-try)

- **OpenAI 发布 GPT-6.1 Sol,DevDay 2026 发布 20 余项更新**
  - 摘要:GPT-6.1 Sol 以显著更低的 token 成本提供"接近 Astra"的编程、电脑操作与专业工作能力;同日 Google 发布 Gemini 4 Argon,定位编程与网络安全。
  - 为什么值得关注:头部模型在低成本下逼近旗舰能力,企业 Agent 的性价比基线再次上移。
  - 链接:[GPT-6.1 Sol](https://openai.com/index/introducing-gpt-6-1-sol)、[DevDay 回顾](https://openai.com/index/devday-2026-recap)、[Gemini 4 Argon](https://deepmind.google/blog/gemini-4-argon-our-next-era-of-frontier-intelligence/)

- **NVIDIA OpenShell:面向自主 Agent 的安全私有运行时**
  - 摘要:GitHub 当日趋势榜开源项目,为自主 AI Agent 提供受控的安全运行环境。
  - 为什么值得关注:企业级 Agent 操作楼宇/设备系统时,权限隔离与可审计是落地前提,可作为运行时方案参考。
  - 链接:[GitHub](https://github.com/NVIDIA/OpenShell)
